## 5. 🛠️ Design System Primitives & UI Foundations
전문가 수준의 도구(Pro-Tool)로서의 완성도를 위해 누락된 필수 컴포넌트 및 기반 시스템을 정립해야 합니다.

### Essential Primitives (누락된 요소)
- [ ] **Overlay System (Tooltip, Popover)**: 밀도 높은 UI에서 필수적인 컨텍스트 정보 제공을 위한 표준화된 Popover/Tooltip 시스템 구축.
- [ ] **Modal / Dialog Stack**: 중요 설정 및 분리된 인터랙션을 위한 포커스 베이스 모달 시스템.
- [ ] **ContextMenu**: 전문가용 도구의 핵심 효율성을 위한 우클릭 컨텍스트 메뉴 표준화 (WIP: CascadingMenu 연계).
- [ ] **Skeleton / Loading**: 페이지 및 블록 레벨의 상태 전환 시 인지 부하 감소를 위한 Skeleton 시스템.
- [ ] **Toast / Notification**: 비동기 작업 결과 피드백을 위한 전역 알림 시스템.

### Structural Improvements (구조 개선)
- [ ] **Resizable Shell Grid**: `Shell` 레이아웃에 드래그 가능한 Gutter를 도입하여 사용자가 사이드바/패널 크기를 조절 가능하도록 개선 (Red Team 피드백).
- [ ] **Semantic Token Expansion**: 현재 Zinc 위주의 토큰을 `surface.error`, `surface.warning`, `surface.success` 등 의미 중심의 표면(Surface) 타입으로 확장.
- [ ] **Keyboard Navigation & Focus**: 모든 프리미티브에 대한 키보드 접근성(Tab Order, Focus Ring) 표준화 및 전체 도구 적용.
- [ ] **Subgrid Design Pattern**: 복잡한 그리드 정렬(예: Form 레이아웃)을 위해 CSS Subgrid 유틸리티 및 가이드 제공.
