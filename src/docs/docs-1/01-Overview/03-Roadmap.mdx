# Future Roadmap

`Common Patterns`에서 도출된 잔여 과제 및 향후 고도화 예정인 컴포넌트들입니다.

## 1. PageShell (Layout System)
도구 지향적 인터페이스의 고수준 레이아웃(Sidebar + Header + Content)을 관리하는 표준 쉘.
- **Goal**: Full-height flex 레이아웃 자동 제어 및 반응형 대응 내장.
- **Source**: `api-docs/components/ApiDocsLayout.tsx`의 `PanelGroup` 패턴을 표준화하여 `AdminLayout`, `MailLayout`에 적용.

## 2. Data Grid (Basic Table)
고밀도 인터랙티브 테이블 컴포넌트.
- **Goal**: 행 선택(Selection), 가변 높이(Density), Sticky Header 지원.
- **Source**: `admin/components/DataTable.tsx`를 제네릭 프리미티브로 승격 (User/Role 등 하드코딩 제거).

## 3. ResizablePanel
사용자가 패널 너비를 조정할 수 있게 하는 레이아웃 프리미티브.
- **Goal**: 드래그 핸들 및 최소/최대 너비 제약 설정 지원.
- **Status**: `api-docs`는 이미 사용 중. `mail`과 `admin` 레이아웃을 이 기반으로 마이그레이션 필요.

## 4. Overlay System (Preview)
공통 `<Overlay>` 프리미티브를 공유하는 고수준 오버레이.
- **Goal**: 포커스 트래핑, Esc 닫기, 표준 진입 애니메이션 적용.

## 5. Search & Filter (Preview)
전역 검색 및 필터링을 위한 컴포넌트 (`SearchFilterBar`).
- **Source**: `mail/components/Header.tsx`의 검색 바 스타일 및 동작을 `FeatureHeader` 프리미티브로 추출.

## 6. Empty State
데이터가 없는 상태를 위한 표준 일러스트 및 가이드 컴포넌트.

## 7. Tree Navigation (New)
파일 탐색기, 문서 사이드바 등을 위한 중첩 가능한 트리 네비게이션.
- **Source**: `api-docs/components/ApiNavigation.tsx`에서 로직 추출.

## 8. Property Inspector (New)
객체 속성을 편집하는 우측 사이드바 패널 (Form/Table Builder 등에서 사용).
- **Source**: `admin/components/FormBuilderPage.tsx`의 `PropertySection` 패턴 표준화.

## 9. Sortable Primitives (New)
드래그 앤 드롭 정렬을 위한 headless hook 및 컴포넌트.
- **Source**: `admin/components/TableBuilder.tsx`의 `@dnd-kit` 구현을 `SortableList`로 추상화.
