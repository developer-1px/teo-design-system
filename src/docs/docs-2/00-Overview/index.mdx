# Components & Primitives

Welcome to the Component Library documentation. This space contains detailed documentation for all UI primitives, composite components, and logic blocks used in the application.

## Structure

- **Primitives**: Base-level UI components (Buttons, Inputs, Layouts).
- **Composites**: Higher-level composed components.
- **Logic**: Headless logic and state management blocks.

Select a component from the sidebar to view its documentation, props, and usage examples.
