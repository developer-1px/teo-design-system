# Primitives

Below is a list of all available UI primitives in the system.

> **Note**: This list was updated on 2026-02-06 to reflect actual implementations.

## Layout
- [Shell](/docs/05-Primitives/shell) - The main application shell structure.
- [Panel](/docs/05-Primitives/panel) - Sidebar and auxiliary panels.
- [TopBar](/docs/05-Primitives/topbar) - Header navigation bar.
- [Resizable](/docs/05-Primitives/resizable) - IDE-grade resizable panel layouts.

## Form Controls
- [Button](/docs/05-Primitives/button) - Interactive action triggers.
- [TextInput](/docs/05-Primitives/textinput) - Text entry fields.
- [Select](/docs/05-Primitives/select) - Dropdown selection.
- [Checkbox / Switch / Radio](/docs/05-Primitives/controls) - Toggle controls.

## Data Display
- [Table](/docs/05-Primitives/table) - Data tables.
- [Tree](/docs/05-Primitives/tree) - Hierarchical tree views.
- [Accordion](/docs/05-Primitives/accordion) - Collapsible content sections.
- [Badge / Avatar](/docs/05-Primitives/badge) - Status indicators and avatars.
- [Progress](/docs/05-Primitives/progress) - Progress indicators.

## Feedback & Overlay
- [Overlay](/docs/05-Primitives/overlay) - Modals, drawers, and popovers.
- [Tabs](/docs/05-Primitives/tabs) - Tabbed navigation.
- [Toolbar](/docs/05-Primitives/toolbar) - Action toolbars.
